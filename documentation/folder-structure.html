Project structure

The solution separates the server host from the interactive client. Client features are grouped by domain.

Rynzo.slnx
Rynzo/                         ASP.NET Core host
  Components/                  App shell and host pages
  wwwroot/                     Static assets and theme
Rynzo.Client/                  Blazor WebAssembly client
  Features/<Feature>/Pages/    Routed Razor pages
  Features/<Feature>/Components/Reusable views
  Features/<Feature>/Models/   Feature models
  Features/<Feature>/Services/ Client state and data
  Layout/                      Navigation and shell
  Theme/                       Theme integration
scripts/                       Design-token sync
documentation/                 Product and developer guides

Key files

AreaSourcePurpose
Host startupRynzo/Program.csServices, middleware, interactive routes.
Page routesRynzo.Client/Features/Razor pages and @page directives.
Scoped styles*.razor.cssPage and component presentation.
Shared stylesRynzo/wwwroot/theme/Tokens, typography, layout, components.
Theme sourceRynzo.Client/Theme/design-system.jsonInput to the design sync script.
NavigationRynzo.Client/Layout/Data/layout-source.jsonNavigation groups and links.

Feature data

Some dashboard sample data is embedded from feature JSON files in the client assembly. Inspect each feature’s service and model before assuming persistence or shared server state.
