DESIGN SYSTEM

Customization

Make changes in the source layer that owns the behavior, and reuse shared patterns to keep the workspace consistent.

Brand assets

Active Rynzo artwork is under Rynzo/wwwroot/assets/images/logos/. Update the matching light/dark variants and favicon references together. Preserve aspect ratio and accessible names.

Update theme values

Edit the source file Rynzo.Client/Theme/design-system.json, then regenerate the compiled theme files:

node scripts/sync-design.cjs

Generated files include C# theme settings and Rynzo/wwwroot/theme/design-tokens.css and design-system.css. See Theme & colors.

Change a page

Use the page’s .razor and sibling .razor.css for local UI changes. Preserve existing bindings and handlers, keyboard behavior, responsive layouts, and empty states.

Add a route

  1. Create a Razor page under Rynzo.Client/Features/<Feature>/Pages/.
  2. Add the @page directive.
  3. Register its navigation link in the layout source when needed.
  4. Regenerate the route inventory with node scripts/sync-documentation.cjs.

API integrations

Use the typed client infrastructure. Keep secrets on the server, validate access on the server, and add loading, error, and retry states in the UI.
