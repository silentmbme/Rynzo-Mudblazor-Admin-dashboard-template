RELEASE

Build and deploy

Rynzo is an ASP.NET Core hosted Blazor WebAssembly app. Publish the server project to create deployable output.

Publish a release

dotnet restore Rynzo.slnx
dotnet publish Rynzo/Rynzo.csproj -c Release -o ./publish

Deploy publish/ with an ASP.NET Core 10 hosting environment such as IIS, Azure App Service, or a Linux host with the .NET runtime installed. Configure the web server to run the published host.

Client handoff checklist

  • Confirm the host supports ASP.NET Core 10, or publish self-contained for its runtime.
  • Set production environment variables and secrets on the host, not in source control.
  • Configure HTTPS and the production hostname.
  • Verify deep links such as /apps/kanban and /finance/expenses.
  • Confirm API endpoints, CORS, authentication, and network access before connecting live data.
  • Review sample-data behavior and replace demo services with approved integrations.

Runtime-specific publish

dotnet publish Rynzo/Rynzo.csproj -c Release -r win-x64 --self-contained false -o ./publish

Change win-x64 to match the target. Framework-dependent output needs the .NET 10 runtime on the server.

Configuration

The host binds the optional ExpressApi section to ExpressApiOptions. Keep credentials and environment URLs outside source control. Validate configured API URLs and timeouts in the target environment.
