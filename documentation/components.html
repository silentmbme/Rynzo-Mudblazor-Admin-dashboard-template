UI REFERENCE

UI components

Rynzo combines MudBlazor controls with shared Razor components and project CSS. Reuse existing patterns before adding another primitive.

PatternSourceUse
Workspace shellRynzo.Client/Layout/Navigation, app bar, menus, and page frame.
Feature viewsFeatures/<Feature>/Components/Reusable domain-specific UI.
Shared stylesRynzo/wwwroot/theme/Tokens, layout, and common components.
Scoped styles*.razor.cssPage and component presentation.

Interaction guidance

  • Use semantic buttons and links with accessible labels.
  • Preserve bindings and event handlers when updating presentation.
  • Give dialogs, popovers, and drawers clear dismissal and focus behavior.
  • Show useful loading, empty, error, and success states.
  • Keep forms responsive and labels associated with inputs.
  • Use semantic status colors and readable contrast.

State and data

Inspect the feature service before describing persistence. Some pages use embedded JSON and client-side state. Do not describe a sample action as a server transaction unless the backend confirms it.
