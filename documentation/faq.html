Frequently asked questions

How do I start the app?

Run dotnet run --project Rynzo/Rynzo.csproj --launch-profile http from the repository root and open http://localhost:5245.

Do I need Node.js?

Not to restore, build, or run the app. Node.js is only needed for the optional design-token synchronization script.

Where do I change shared colors?

Edit Rynzo.Client/Theme/design-system.json and run node scripts/sync-design.cjs. See Theme & colors.

Where is a page route defined?

Find its @page directive under Rynzo.Client/Features/ or use Pages & routes.

Does every page save data to a backend?

No. Some workspaces use embedded sample data and client-side state. Confirm the feature service before relying on persistence or cross-user sync.

How do I prepare a client build?

Publish with dotnet publish Rynzo/Rynzo.csproj -c Release -o ./publish, then deploy with an ASP.NET Core 10 host. Configure HTTPS, environment settings, and approved integrations on the server.

Why does a deep link fail after deployment?

Check host routing and Blazor fallback behavior, then inspect production logs and verify the route locally.
