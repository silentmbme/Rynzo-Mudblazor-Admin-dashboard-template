Support & troubleshooting

Use source files and runtime logs to diagnose setup and integration issues.

When reporting an issue

  • Include the command, route, browser, and environment.
  • Include the first relevant error, not only the final summary.
  • Note whether it reproduces in a clean Release build.
  • Remove secrets, personal data, and production identifiers from logs.

Common checks

SymptomCheck
SDK not foundInstall the .NET 10 SDK and restart the terminal.
Port unavailableStop the process using port 5245 or change the HTTP launch profile.
Theme changes missingRun node scripts/sync-design.cjs and rebuild.
Route not foundCheck the Razor @page directive and host fallback.
Live data missingCheck API configuration, network access, CORS, authentication, and server logs.

Useful commands

dotnet --info
dotnet restore Rynzo.slnx
dotnet build Rynzo.slnx -c Release
