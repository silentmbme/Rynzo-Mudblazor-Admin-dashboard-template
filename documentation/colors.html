APPEARANCE

Theme & colors

Shared palettes, type, spacing, and shell defaults are sourced from the Rynzo design system and generated into CSS and C#.

FileRole
Rynzo.Client/Theme/design-system.jsonSource for palettes, fonts, spacing, and shell defaults.
Rynzo.Client/Theme/EdzenDesignTokens.g.csGenerated MudBlazor palettes.
Rynzo.Client/Theme/EdzenThemeSettings.g.csGenerated type, skin, and layout defaults.
Rynzo/wwwroot/theme/design-tokens.cssBrowser palettes, radius, and shadows.
Rynzo/wwwroot/theme/design-system.cssBrowser font and spacing variables.

Regenerate theme files

Regenerate theme filesAfter editing Rynzo.Client/Theme/design-system.json, run node scripts/sync-design.cjs from the repository root. The generator updates the client C# palette and settings plus the shared browser CSS.

The script uses Node.js built-in modules and has no npm dependencies. Generated files are included, so running the app does not need Node.js.

Appearance preferences

The shell supports light, dark, and system modes, color skin, layout direction, density, and sidebar presentation. Browser preference keys are rynzo-admin-settings and rynzo-sidebar-color. Startup bootstrap applies saved settings early.

Contrast and skin support

Set semantic foreground and background colors together. Check focus indicators, charts, disabled controls, and sidebar navigation in light and dark modes. Keep supported skin names in sync across generated settings, bootstrap validation, and appearance controls.
