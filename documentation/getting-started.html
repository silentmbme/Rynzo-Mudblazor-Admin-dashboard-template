Getting started

Run Rynzo locally with the .NET SDK. Node.js is only needed for the optional design-token synchronization script.

Prerequisites

  • .NET 10 SDK installed and available on PATH.
  • Current browser with JavaScript and WebAssembly support.
  • Node.js only when editing design tokens and regenerating theme outputs.

Restore and run

From the repository root in PowerShell:

dotnet restore Rynzo.slnx
dotnet run --project Rynzo/Rynzo.csproj --launch-profile http

Open http://localhost:5245. The http launch profile uses Development settings.

Build the solution

dotnet build Rynzo.slnx -c Release

Run from Visual Studio

Set Rynzo as the startup project and choose the http launch profile.

Sample data and persistence

Some workspaces initialize from JSON embedded in the client assembly; some interactions update in-memory client state. Appearance preferences are stored in browser storage. Do not assume a demo action writes to a production database or synchronizes between users. Connect and validate a backend before using the workspace for live records.
