RYNZO DOCUMENTATION

Blazor · .NET 10

Build with the Rynzo workspace.

A practical guide to running, customizing, and shipping Rynzo. The application combines an ASP.NET Core host, an interactive Blazor WebAssembly client, MudBlazor, and a shared design system.

Run the project →Browse pages
HostASP.NET Core

Serves the app and hosts the interactive client.

ClientBlazor WebAssembly

Razor pages, feature components, and client state.

UI libraryMudBlazor 9

Accessible controls with Rynzo’s shared UI system.

Target.NET 10

Restore, build, run, and publish with the .NET SDK.

Workspace features

Business dashboards

Executive, analytics, finance, commerce, CRM, projects, HRM, hospital, school, logistics, crypto, LMS, SaaS, marketing, and restaurant.

Everyday apps

Email, chat, AI chat, calendar, tasks, notes, Kanban, and file manager.

Shared design system

Responsive shell, appearance settings, forms, tables, charts, and reusable Razor components.

Quick start

dotnet restore Rynzo.slnx
dotnet run --project Rynzo/Rynzo.csproj --launch-profile http

The app opens at http://localhost:5245. See Getting started for prerequisites and troubleshooting.
