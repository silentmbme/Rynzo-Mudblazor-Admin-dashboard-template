WORKSPACE

Layout & navigation

A shared shell keeps navigation, search, appearance, notifications, and account controls available across feature pages.

Shell regions

  • Top app bar: global search, quick access, notifications, display, theme, and account actions.
  • Sidebar: grouped dashboard and application routes in expanded or compact modes.
  • Page region: routed feature content and page-specific actions.
  • Appearance panel: mode, skin, density, direction, and layout preferences.

Navigation source

Rynzo.Client/Layout/Data/layout-source.json supplies navigation groups and links. Keep each link aligned with the Razor page’s @page directive.

Responsive behavior

At narrow widths the shell changes sidebar presentation and page controls adapt. Use the page-scoped stylesheet and existing responsive patterns; review keyboard focus and overflow on desktop and mobile.

Scroll ownership

The shell owns the primary page scroll. Constrain any inner scrolling region to its available height. Menus and drawers should keep overflow inside their overlays instead of expanding the page.
